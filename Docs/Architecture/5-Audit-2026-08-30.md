## Findings

1. **Two static mutable fields remain inside `Sim/`.**
   `Assets/Scripts/Sim/Run/MasterControl.cs:17` — `public static int HatchWaves = 1`.
   Production no longer reads it for the finale; Hatch-bank fixtures and tests still write
   and restore it. `Assets/Scripts/Sim/Run/IntensityJuice.cs:11` —
   `public static bool Enabled = false` on `Ante` (parked 2026-08-30; EditMode spend-path
   tests flip it). `TwoRunIsolationTests.SimAssembly_HoldsNoStaticMutableState` asserts
   zero and will fail on both. Disprove: both fields are `const` or `static readonly`, or
   gone, and that test lists zero violations.

2. **`ShipLookPass` is a second `[MenuItem]` root.**
   `Assets/Scripts/Editor/Scenes/ShipLookPass.cs:25` —
   `[MenuItem("Tools/Scenes/Ship/Apply Look Pass", ...)]`;
   `:405` — `[MenuItem("Tools/Scenes/Ship/Bake Look Lighting", ...)]`.
   Fence is one root, `GatekeepersProtocol/`. `lint-arch` scans `Assets/Scripts` and will
   fail both rows as `menu-item-outside-root`. Disprove: both paths sit under
   `GatekeepersProtocol/` and are named in `menu_rows`, or both `[MenuItem]` attributes are
   gone.

3. **Prompt getters and FORGE charge labels still allocate on the frame path.**
   Reached via `Interactor.Tick` → `_current.Prompt` (`Interactor.cs:84`) and HUD
   `LateUpdate` → `PushValues` → `PushProtocolReadout` (`HudController.Fight.cs:162`):
   - `Assets/Scripts/Game/Bastion/HatchRecallPad.cs:69-71` — `"[" + e + "] …"` every frame
     the pad is in view. New since 08-25.
   - `Assets/Scripts/Game/Player/PlayerProtocolAbilities.cs:131-132,163-164` —
     `TurretChargeLabel` / `OutriderChargeLabel` concatenate `ToString()` results.
     `HudController.Protocol.cs:47-48,57-58` calls `TryCrewChargeSquare` /
     `TryPersonalChargeSquare` **before** the cache compare, so a live FORGE machine
     allocates every `LateUpdate`. `CdLabel` in the same file uses a interned table and does
     not.
   - Leftover concat from 08-25, now the minority branch: `RepairInteractable.cs:112,115-116`
     (Docking / Dock); `StationTerminal.cs:54` (sealed-while-boarding); `BastionTerminal.cs:120,122`
     (Convert / Resources stubs). Convert / start-wave / live-terminal paths now use the
     cached `StringBuilder`.
   Disprove: those getters return interned or cached strings, and `Try*ChargeSquare` does
   not allocate on the cache-hit path.

4. **Three sampled tunables still have no `Reset()`.**
   `PlayerHealth.cs:20` (`maxHp`), `RepairInteractable.cs:27` (`repairPerSecond`),
   `Interactor.cs:25` (`range`). The 08-25 named combat/weapon set now complies; these three
   still serialize a code default with no `Reset()` to keep the prefab from drifting.
   Disprove: each implements `Reset()` that writes the same numbers as the field initializers.
