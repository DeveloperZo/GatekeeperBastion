text here.

## Constraints

- First Bastion through Master Control. No second destination. No new resource.
- No companion. No siphon. No CREW lock behind death. No pause that stops time.
- Capsule is furniture; `Podded` stays retired.
- Master Control’s win is `M54`. This demo does not add a third ending.
