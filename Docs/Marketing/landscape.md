## Ancestor (public)

[Guns 'n Goblins](https://store.steampowered.com/app/881940/Guns_n_Goblins/)
(Steam app 881940). Demo on Steam (press: 2026-07-24). Full game **Q2 2027**.
Genre on Steam: Action, Indie, RPG. User tags include **FPS, Idler, Incremental,
Building, Survival, Dark Fantasy** (Steam page, not cached in this repo).

Steam blurb: "incremental horde survivor FPS. Build your Bastion, level up your
character, and upgrade your arsenal to rise from Apprentice Bell Ringer to
Master Dragon Hunter."

Press files it the same way:

- GameShed: castle defense + incremental progression; thousands on screen;
  ring the bell to summon more
  ([gameshedge](https://www.gameshedge.com/horde-survival-fps-shooter-guns-n-goblins-pc-announced/))
- FullCleared: "roguelite" / survivor-like; designer quote *why isn't there an
  incremental FPS built around massive hordes*
  ([fullcleared](https://fullcleared.com/news/guns-n-goblins-looks-to-be-our-next-roguelite-obsession/))
- GamingOnLinux: "first-person bullet heaven"
  ([gamingonlinux](https://www.gamingonlinux.com/2026/05/blow-up-thousands-of-monsters-in-the-horde-based-survivor-fps-guns-n-goblins/))

What **this** project kept (Design, not Steam): you call the swarm; a lost Run
still pays. What it inverted: Bastion is **theirs**; you board. What it refused:
idler, incremental hero sheet, build-your-fortress, thousands-strong spectacle,
single-player as the only session (`../Design/1-Experience.md` §1.1 ancestor).

**Reception risk:** any copy that shares their verbs (deluge, rebuild, XP,
thousands, "your Bastion") will be reviewed as a GnG clone. The shared DNA is
real; the shelf is fatal if we land on Idler / Incremental / Bullet Heaven.

## Comparisons we can afford

**Say (when friends-alpha is real):** you and a friend board a garrison, you
start every fight, you leave with what made it through the Hatch.

**Do not say:** Vampire Survivors with a mouse; GnG in space; Left 4 Dead with
a siphon; a tower-defense FPS.

## Design take vs refuse (internal)

| Title | Took | Refused |
|---|---|---|
| Guns 'n Goblins | Call the swarm; progress through failure | Their Bastion, idle, XP sheet, thousands, skeleton army |
| Killing Floor 2 | Identity at hour zero (Default 0-salvage claim) | Level-0 hollow perk start (`boarder-protocols.md`) |
| Vermintide | Subtraction as identity; Challenge as man-sized taunt | Talent quota filler; numeric DR tank |
| Payday 2 | Deployable as a verb; never price transformed hardware above the plain item | Sentry-as-best-item; Joker as default fantasy |
| Deep Rock | Tools carry class; day-one free classes | Unused-overclock quota; Dash as identity |
| GTFO | Hostile facility, loadout before drop | Four-player requirement, stealth as the loop |
| PoE Headhunter | Invert: elites wear what you wear (panel waits on the modifier probe) | Rolled rare mods (determinism, illegible mid-fight) |
| Mass Effect Soldier / AW Andy | Default = unmodified assault baseline | Specialist as the day-one class |
| Kingdom Rush | 1-of-2 twists change the job, not the number | Deleting dead branches (Alliance backlash). Flat-number hammers are Hades, not KR |
| Boss Room | Readable 4p NGO lobby / host scene | FishNet / Fusion / Quantum; Boss Room as a sim mandate |
| Aliens: Fireteam Elite | Distinct-verb ability spread per class (turret / heal-buff / detection / AoE / squad-buff), never four flavors of one thing; a symmetric, legible risk card (flat +50% dealt and taken) reads clean | Randomized card draw over player-authored choice; a stakes system players report as "doesn't matter" below the top difficulty tier; a numeric aggregate power score (Combat Rating) summed across gear |

## Accurate vs failed impression

**Accurate:** sci-fi FPS; you are the Boarder; they hold the Bastion; quiet
until you ante up and start; banked Salvage survives a loss; a friend is the
aim of the roadmap.

**Failed:** incremental; idler; bullet heaven; castle defense; thousands on
screen; you rebuild **your** Bastion; AEGIS or LEDGER in the trailer (VEIL and
FORGE ship and may appear); plural destinations.
