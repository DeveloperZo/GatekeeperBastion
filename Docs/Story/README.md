The story is not the point. The Run is the point. This folder exists so the Run feels like
it is happening somewhere real, to someone, for a reason, and so that the words in the game
pull in one direction instead of four.

The order to read it in:

- [Premise](Premise.md). The fantasy, what everything in the world actually is, the idea
  underneath it, and the rules that keep it small. If only one file survives, this is it.
- [Beats](Beats.md). Seven, from the player's chair, each tied to something already in the
  build or already being written.
- [Voices](Voices.md). Who writes the Compendium. This is the main delivery mechanism and
  the place the fantasy actually reaches the player as text.
- [Open-Rulings](Open-Rulings.md). What Zo has not decided, and the assumptions made in the
  meantime so work could continue.

## The budget

Three carriers, and nothing else:

- the Compendium entries in `../Play/`, which are being written anyway;
- state the game already tracks and already shows;
- at most one repeated line at the Hatch, if a beat cannot land without it.

A beat that needs a fourth thing is a beat that is wrong.

## Do not build

- A narrator, an AI companion, a voice on the Ship that knows things.
- Collectible lore: logs, audio diaries, terminals with backstory on them.
- A named character anywhere in the Compendium.
- A Gatekeeper that talks, or an elite that exists to deliver a line.
- Any entry, prompt or screen that raises how the Boarder returns.
- A revelation moment, an achievement for reaching it, or a check for whether the player
  understood.
